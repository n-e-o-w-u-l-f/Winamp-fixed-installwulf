Install-Wulf

A carefully documented installer pipeline for turning a supplied Winamp installer into a consistent Windows installation package.

Read the manualBuilds & downloads

THE IDEA

One source. One build recipe. One verifiable result.

Install-Wulf keeps the installer logic in source control. When the approved Winamp source installer changes, the repository can rebuild the package through GitHub Actions instead of relying on a manually modified executable.

01

Source

Place the permitted Winamp source installer at the documented input path.

02

Build

GitHub Actions extracts, validates and packages the payload with NSIS 3.12.

03

Verify

The generated executable is checked for existence, PE structure and SHA-256.
