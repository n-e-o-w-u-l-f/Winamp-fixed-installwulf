How to Use Install-Wulf

An intentionally thorough guide to downloading, installing, verifying and troubleshooting the package.

1. Before you begin

Use a supported Windows system and obtain Install-Wulf from a project release or build artifact. If you are updating the project itself, make sure you have the legal right to redistribute the Winamp source installer used by the build.

2. Download

Open the project's GitHub Releases or Actions artifacts and download Winamp_InstallWulf-fixed.exe. If a SHA-256 checksum is published, verify it before running the file.

Get-FileHash .\Winamp_InstallWulf-fixed.exe -Algorithm SHA256

3. Start the installer

Double-click the installer. Windows may display a User Account Control dialog because installing into Program Files requires administrator permission. Read the publisher information and choose Yes only when you trust the installer source.

Important: Install-Wulf does not require disabling UAC, Defender, SmartScreen or other Windows security controls.

4. Installation destination

The default destination is the 32-bit Program Files location used for the Winamp installation. The installer copies the packaged payload and creates the normal Windows uninstall registration.

5. Finish and launch

After installation, verify that winamp.exe exists in the installation directory. Launch Winamp using its normal executable or shortcut.

6. If Windows blocks Winamp

Do not immediately disable protection. A block may originate from Authenticode validation, SmartScreen, Defender, AppLocker, WDAC/Code Integrity, enterprise policy or Mark-of-the-Web. Capture the exact message and event first.

  1. Check the exact Windows dialog text.
  2. Check Windows Security protection history.
  3. Check Event Viewer for AppLocker/Code Integrity events where applicable.
  4. Compare the behavior with the original Winamp executable.
  5. Record the installed Winamp file version and Install-Wulf checksum.

7. Updating the source

For maintainers, replace winamp/winamp_latest_installer.exe with the permitted updated source, update its documented identity in config/build-config.json, commit it, and push to main. The build workflow calculates and publishes the source SHA-256; a release requires that hash to be pinned before promotion.

8. Local build

Install the exact tool versions documented in config/build-config.json, then run:

.\scripts\build-installer.ps1
.\scripts\verify-installer.ps1 -Installer .\build\output\Winamp_InstallWulf-fixed.exe -ConfigFile .\config\build-config.json -PayloadDirectory .\build\payload

9. Uninstall

Use Windows Installed Apps/Programs and Features and select the Install-Wulf (Winamp) entry. The generated uninstaller removes the installation directory and its Install-Wulf uninstall registration.

10. What Install-Wulf does not do

  • It does not disable Windows UAC.
  • It does not add hidden Defender exclusions.
  • It does not bypass Winamp licensing or activation.
  • It does not replace original vendor signatures.
  • It does not silently download arbitrary payloads.
